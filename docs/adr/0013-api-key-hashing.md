# ADR-0013: SHA-256 Digests For API Keys

- Status: Accepted
- Date: 2026-11-19
- Deciders: Project maintainer
- Affected requirements: FR-KEY-02, NFR-PERF-01

## Context

Keys are checked on every API request. Password hashing functions like argon2id cost tens of milliseconds by design.

## Alternatives

- argon2id with a lookup prefix.
- SHA-256 of a 256-bit random key, indexed.

## Decision

Keys are 32 random bytes encoded base64url with no recognizable prefix. SOAbox stores the SHA-256 digest and looks keys up by digest. Passwords still use argon2id.

## Rationale

A 256-bit random secret cannot be brute forced, so a slow hash adds cost without security. No prefix means a key reveals nothing about SOAbox.

## Consequences

Keys must always be generated by SOAbox, never chosen by people.
